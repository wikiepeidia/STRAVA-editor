# STRAVA-editor

Strava editor for editing strava stuffs

## Tool 1 : Shift strava timestamp

- Download your GPX file
- Utlize <https://github.com/wikiepeidia/STRAVA-editor/blob/f6403272499e419dac03f8c5a8ae193023603c2f/strava_timestamp_gui.py> to convert the older timestamp into the new one
- Use case: if your watch failed to measure /out of battery when this run is essential, so that you dont really lose anything
